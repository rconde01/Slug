* There is a GPU text rendering library called slug.
* You can get some overview at https://terathon.com/blog/decade-slug.html
* The original paper describing the algorithm is at https://jcgt.org/published/0006/02/02/paper.pdf
* The latest reference shaders are at ./SlugPixeShader.hlsl and ./SlugVertexShader.hlsl

I want you to create a webgpu enabled webpage which makes a demo of this approach.
* Window displaying the text and a trackball like control so you can rotate it
* Textbox to specify the text to render

You should commit your progress as you go and keep a detailed document of all the steps.
